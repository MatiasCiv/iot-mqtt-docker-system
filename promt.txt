Estoy desarrollando un sistema IoT distribuido para monitorización y control de cultivos basado en microservicios y desplegado mediante Docker Compose.

✅ Estado actual del proyecto (100% operativo):

He construido un sistema funcional con arquitectura desacoplada basada en MQTT, con los siguientes servicios:

---

🏗️ Arquitectura general:

El sistema está compuesto por tres contenedores principales:

1. Servicio de Ingesta (Python - "BLE Service"):
- Lenguaje: Python 3.11
- Librerías: paho-mqtt, bleak (preparado), random (simulación)
- Función actual:
  - Generación de datos simulados de sensores (temperatura y humedad)
  - Publicación periódica en MQTT cada ~5 segundos
- Modo actual:
  - SIMULACIÓN (no BLE real aún)
- Topic utilizado:
  - "ble/readings"

---

2. Broker MQTT (Mosquitto):
- Tecnología: Eclipse Mosquitto
- Puerto: 1883
- Función:
  - Gestionar la comunicación desacoplada mediante publish/subscribe
- Estado:
  ✅ 100% funcional
  ✅ múltiples clientes conectados (Python + .NET)

---

3. Backend (.NET - "El Cerebro"):
- Tecnología: ASP.NET Core (NET 8)
- Librería MQTT: MQTTnet
- Función:
  - Suscripción al topic "ble/readings"
  - Recepción de datos en tiempo real
  - Procesamiento inicial (actualmente logging en consola)
- Estado actual:
  ✅ Conectado a MQTT
  ✅ Suscripción activa
  ✅ Recibiendo mensajes correctamente

Ejemplo de mensaje procesado:
{
  "deviceId": "ESP32_SIM",
  "temperatura": 27.1,
  "humedad": 43.17
}

---

🐳 Orquestación:

Todo el sistema está orquestado mediante Docker Compose:

Servicios definidos:
- mqtt
- ble-service
- backend

Red interna Docker:
- Los servicios se comunican mediante hostname (ej: "mqtt")
