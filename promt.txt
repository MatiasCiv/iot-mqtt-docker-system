Estoy desarrollando un sistema IoT completo para monitorización y automatización de cultivos, basado en arquitectura distribuida con microservicios y comunicación mediante MQTT, desplegado con Docker Compose.

El sistema actualmente está en una fase avanzada donde ya incluye:

- adquisición de datos en tiempo real
- persistencia
- lógica de negocio
- visualización avanzada
- automatización cíclica en backend
- preparación para control físico de actuadores (válvulas vía Bluetooth + Arduino)

---

🏗️ ARQUITECTURA GENERAL

Sistema desacoplado basado en eventos:

[UI Web]
    ↓ HTTP
[Backend .NET (ASP.NET Core)]
    ↓ MQTT publish/subscribe
[Python BLE Service]
    ↓ Bluetooth (HC-05)
[Arduino]
    ↓
Actuadores físicos (relés / válvulas / bomba)

Y en paralelo:

[Python BLE Service] → MQTT → [.NET] → SQLite

---

🔧 COMPONENTES DEL SISTEMA

---

1. ✅ BLE SERVICE (Python)

- Lenguaje: Python 3.11
- Función:
    - Simulación de sensores (temperatura y humedad)
    - Publicación periódica (~5s)
    - Puente MQTT ↔ Bluetooth

Publica en:
- Topic: "ble/readings"

Recibe:
- Topic: "ble/commands"

Responsabilidades:
- enviar datos a .NET
- recibir comandos y transmitirlos al Arduino

---

2. ✅ MQTT BROKER (Mosquitto)

- Puerto: 1883
- Comunicación desacoplada

Topics principales:
- ble/readings (sensores)
- ble/commands (actuadores)
- ble/status (estado Arduino, futuro)

---

3. ✅ BACKEND (.NET 8)

- Framework: ASP.NET Core Minimal API
- ORM: Entity Framework Core (SQLite)
- MQTTnet para comunicación

Funciones:

✅ Recepción de datos MQTT en tiempo real  
✅ Persistencia en SQLite  
✅ API REST completa  
✅ Lógica de cultivo (etapas)  
✅ Motor automático en segundo plano (BackgroundService)  
✅ Preparación para control de actuadores

🧠 MODELO DE NEGOCIO

Relación principal:

Cultivo
 ├── sensor (DeviceId)
 ├── relay (actuador físico)
 └── etapas

---

🧠 CÁLCULO DE ETAPA ACTUAL

dinámico:

dias = DateTime.UtcNow - FechaInicio

Recorrido acumulativo de etapas → determina etapa actual

---

🔁 AUTOMATIZACIÓN (BackgroundService)

Servicio que corre cada X segundos:

Flujo:

1. Obtener cultivos
2. Obtener última lectura por sensor
3. Obtener etapas
4. Calcular etapa actual
5. Evaluar condiciones:

if (humedad < etapa.HumedadMin)
    → activar válvula (pendiente MQTT)

---

💧 EJEMPLO DE LÓGICA

if lectura.Humedad < etapa.HumedadMin:
    Console.WriteLine("💧 Riego necesario")
    → (futuro) enviar comando MQTT
