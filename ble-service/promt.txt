Estoy desarrollando un sistema IoT para monitorización de cultivos basado en microservicios y desplegado con Docker.

🔥 Estado actual del proyecto:

✅ Arquitectura definida (microservicios en contenedores Docker)
✅ Servicio de ingestión en Python funcionando dentro de Docker
✅ Backend en .NET funcionando como API REST
✅ Comunicación entre servicios verificada (HTTP)
✅ Persistencia de datos implementada con SQLite

---

🏗️ Arquitectura actual:

1. Servicio de Ingesta (Python - "El Oído"):
- Lenguaje: Python 3.11
- Librerías: bleak (BLE), requests (HTTP)
- Despliegue: contenedor Docker
- Funcionalidad actual:
  - Simulación de datos de sensores (temperatura y humedad)
  - Envío de datos mediante POST a API .NET cada 5 segundos
- Estado BLE real:
  - Preparado (dependencias instaladas)
  - Pendiente de ejecución en Raspberry Pi (Windows no soporta BLE en Docker)

---

2. Servicio Central (Backend .NET - "El Cerebro"):
- Tecnología: ASP.NET Core (Web API)
- Endpoint activo:
  POST /api/ble
- Funcionalidad:
  - Recepción de datos JSON desde Python
  - Parseo automático a modelo Reading
  - Persistencia en SQLite
- Base de datos:
  - SQLite local (readings.db)
- Modelo actual:

Reading:
- Id (int)
- DeviceId (string)
- Temperatura (double)
- Humedad (double)
- Timestamp (DateTime)

---

🔌 Flujo de datos actual:

Python (Docker)
↓
HTTP POST (cada 5s)
↓
API .NET
↓
SQLite (persistencia)

---

📡 Ejemplo de dato enviado:
